# 日本拉拉熊旅遊圖鑑

公開互動App：https://japan-rilakkuma-travel-atlas.vienk.chatgpt.site/

繁體中文日本旅遊規劃App：探索、買物、活動、美食與多日行程。旅行起訖、人數、目前日期與搜尋城市共用；行程按日保存，跨城市不會刪除原安排。Google Maps提供外部導航，食べログ與San-X／主辦頁保留第一方查核入口。底圖可切國土地理院、OpenStreetMap，搭配N02鐵路及車站圖層。

## 開發與建置

Node22.13以上，npm install後以npm run dev預覽。npm run build會先同步public/atlas.html到伺服器根路由，再由官方Sites Vinext流程產出Worker與靜態資產；不再從舊dist/index.html維護。主要原始碼為public/assets、app、lib與db。D1結構在drizzle，公開Site仍用原project_id；不另建立網站。

Windows目前原生workerd發生存取違例。本次本機互動測試採D槽Node HTTP＋SQLite轉接，同用lib/live-sources的來源更新邏輯。此轉接不代表Cloudflare部署、MCP身分或排程已驗證；正式結果另列qa。

## 內容與功能

- 44個可辨識商品／具名款式、48筆線上或特定現場公開價；未公開品番不製造SKU。已核販售分店、日期、限購與優惠資格另列，沒有全SKU即時庫存。
- 採購保留原始報價通路、來源、查核時間與單價快照；可填採買日、人數、附加費及狀態，取消和範圍外列不計本趟合計。未知附加費的0欄位不能視為免費。
- 17家餐廳、52份菜單，按同一適用餐期與已知必要費用篩選。每盤價不當人均整餐費。預約、取消、放位與臨時營業變動仍須官方確認。
- 4座古蹟深讀、6條動漫關聯方案及14個實際點位；分票區、原構與重建、作品官方關係及御朱印分列。有限主題收集與參訪紀錄保存在此瀏覽器。
- 16組活動／場館時間規則與406個查核時的有日期場次。祇園角冬季／跨年停演、睡魔普通與團體時段各自處理。已公布時刻不等於空位。
- 活動可選日期與場次帶入行程，行程顯示來源、推算結束、交通與排隊預留、衝突、未知費用及範圍外記錄。只匯出有起訖的有效範圍內ICS，亦可匯出完整CSV。
- San-X新聞、新品、門市、PDF與5個太鼓分館為9組固定官方更新來源。D1保存成功快照、變動及錯誤，失敗保留上次成功；MCP更新工具另驗證擁有者身分及固定報價來源。背景排程需依正式連線結果判定，開著網頁重新整理不等於網站關閉後仍更新。

## 照片與資料

34張本機實景／舊照均保留作者、拍攝年份、來源與授權，能在站內放大。新增6張逐張授權及畫面核對見research/media-manifest-2026-11-21.json。區域照不冒充店照，舊照不冒充當期商品。餐廳受限圖不轉存；可用影片只用官方YouTube播放器並標示教學內容，不能當本店現場。遠端官方商品圖載入失敗保留原頁入口，不宣稱已取得獨立重製授權。

研究原稿在research，原始材料與所有執行檔只存D:\Coding\日本旅遊。public/assets/leaflet-LICENSE.txt為Leaflet授權。收藏、採購、行程與進度仍在localStorage，未做跨裝置帳號同步。
